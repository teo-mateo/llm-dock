LIST RULES
  1. Two sections, Live then Ended, labelled in small caps. A section with no sessions is not drawn.
  2. Project header = chevron, project name (mono), total row count including subagents. Click or Enter/Space toggles it.
  3. Default open state: Live projects open, Ended projects closed. A user toggle is remembered per section:project in localStorage (wrapped in try/catch).
  4. A closed project still shows its waiting count (sum of its sessions' open questions) so a question never hides behind a collapsed group.
  5. Subagents sit under their top-level ancestor, indented with a 1px guide line and a ↳ glyph, regular weight, tighter padding.
  6. Order: projects by their most recent session; roots by last_seen desc; subagents by first_seen asc.
  7. A session whose parent is unknown, or whose chain loops, is shown as a root.
  8. The live only checkbox goes away — the collapsed Ended section does its job.
READING COLUMN
  • A subagent's header gets a breadcrumb line: subagent of parent; the parent name navigates to it.
